### Implementing `toString`: Converting a Slice to a String

Our goal is to convert our `deck` type, which is a slice of strings, into a single `string`. This string will then be easy to convert into a `[]byte` for saving to a file. We will accomplish this by implementing the `toString` receiver function.

#### 1. Implementation Steps

The process involves two main steps within the `toString` function:

1. **Type Conversion (`deck` to `[]string`)**: We first convert our `deck` variable back into a plain slice of strings.
2. **Joining the Slice**: We then take that slice of strings and join all its elements into one long string, using a comma as a separator.

#### 2. Using the `strings.Join` Function

Go's standard library provides a package specifically for string manipulation called **`strings`**. Inside this package is a very helpful function, **`Join`**, that is perfect for our needs.

- **`strings.Join(elements []string, sep string)`**: This function takes a slice of strings (`elements`) and a separator string (`sep`). It concatenates all the elements into a single string, with the separator placed between each element.

To use this function, we must first import the `strings` package. When importing multiple packages, you wrap them in parentheses.

**Importing multiple packages in `deck.go`**:

Go

```Go
import (
	"fmt"
	"strings"
)
```

#### 3. The Complete `toString` Function

Now we can combine the type conversion and the `strings.Join` call to complete our `toString` function.

**`deck.go` implementation**:

Go

```Go
func (d deck) toString() string {
	// 1. Convert deck 'd' to a slice of strings
	// 2. Pass it to strings.Join with a comma separator
	return strings.Join([]string(d), ",")
}
```

- `[]string(d)`: This is the **type conversion**. It takes our `deck` variable `d` and treats it as a standard `[]string`.
- `","`: This is the separator that will be placed between each card name.
- `return`: The `strings.Join` function returns the final, single string, which we then return from `toString`.

#### 4. Testing the Function

To see the result, we can call this new method from our `main.go` file and print the output.

**`main.go`**:

Go

```Go
package main

import "fmt"

func main() {
	cards := newDeck()
	fmt.Println(cards.toString())
}
```

When you run `go run main.go deck.go`, the output will be a single, long, comma-separated string of all the cards in the deck, which is exactly what we need for the next step.
