### Preparing Data for Saving: Type Conversion in Go

To save our deck to the hard drive using `ioutil.WriteFile`, we must first solve a data-type problem. Our `deck` is a slice of strings (`[]string`), but the `WriteFile` function requires a slice of bytes (`[]byte`). This section outlines the strategy for converting our data into the correct format.

#### 1. The Strategy: From `deck` to `[]byte`

We will perform a multi-step conversion to get our `deck` into the required `[]byte` format.

1. **`deck` -> `[]string`**: Take our custom `deck` type and treat it as its underlying type, a slice of strings.
2. **`[]string` -> `string`**: Join every string in the slice into one single, continuous string. We will use a comma to separate each card name.
3. **`string` -> `[]byte`**: Convert the single string into its byte slice representation, which can then be saved to a file.

This process of changing a value from one type to another is called **type conversion**.

#### 2. Type Conversion in Go

Type conversion is a common and essential task in Go. It allows you to "cast" a value of one type into another when needed.

**Syntax**: `TypeName(value)`

You wrap the value you want to convert with the type you want to convert it _to_. For example, to convert a string into a byte slice, you do the following:

Go

```Go
greeting := "Hi there!"
byteSlice := []byte(greeting) // Converts the string to []byte
fmt.Println(byteSlice)
// Output: [72 105 32 116 104 101 114 101 33]
```

This simple conversion accomplishes the last step of our strategy. The most challenging part is step 2: turning our slice of strings into a single string.
