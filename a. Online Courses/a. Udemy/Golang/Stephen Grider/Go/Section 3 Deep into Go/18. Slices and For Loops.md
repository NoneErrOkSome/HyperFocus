### Working with Lists: Arrays and Slices in Go

To build a deck of cards, you need a way to manage a list of them. Go provides two data structures for handling lists: **arrays** and **slices**. While they seem similar, they have one key difference that makes slices far more common and flexible in practice.

- **Array**: A fixed-size list of elements. When you create an array, you define its length, and it can _never_ change.
- **Slice**: A variable-size list of elements. A slice can grow and shrink as needed, allowing you to add or remove items.

For our `cards` project, a slice is the perfect choice because the number of cards in a deck or a hand will change as we deal and shuffle.

A critical rule for both arrays and slices is that **all elements must be of the same type**. You cannot have a list that contains both strings and numbers.

### Creating and Using a Slice

You will primarily work with slices in Go. Here’s how you declare, initialize, and use them, as demonstrated in `cards/main.go`.

#### Declaring and Initializing a Slice

The syntax for creating a slice is `[]type{value1, value2, ...}`.

- `[]`: The square brackets indicate you are creating a slice.
- `type`: The data type of the elements the slice will hold (e.g., `string`, `int`).
- `{}`: The curly braces enclose the initial values.

**Example:**

Go

```Go
// Create a slice of strings named 'cards'
cards := []string{"Ace of Diamonds", newCard()}
```

In this example, we create a slice that can only hold strings. We initialize it with one hard-coded string and one string returned from our `newCard()` function.

> **Go Pro Tip:** If you declare a variable but don't use it anywhere, the Go compiler will report an error. This is why we often use `fmt.Println()` during development—to temporarily "use" a variable and prevent this error.

#### Adding Elements with `append`

To add a new element to a slice, you use the built-in `append` function.

**Syntax**: `slice = append(slice, newValue)`

Go

```Go
cards := []string{"Ace of Spades", "Five of Diamonds"}

// Add a new card to the slice
cards = append(cards, "Six of Spades")
```

**Important Note**: The `append` function does **not** modify the original slice. Instead, it creates a _new_ slice containing all the old elements plus the new one and returns it. You must then reassign this new slice back to your original variable (`cards = ...`).

### Iterating Over a Slice with `for...range`

To loop through all the elements in a slice, you use a `for` loop combined with the `range` keyword.

**Syntax**: `for index, element := range slice { ... }`

- `for`: The keyword that starts the loop.
- `range slice`: This tells Go to iterate over every element in the `slice`.
- `index, element :=`: For each iteration, `range` returns two values: the element's index (position) and a copy of the element's value. We use `:=` because these variables are re-declared for each pass through the loop.

**Example:**

Go

```Go
cards := []string{"Ace of Spades", "Five of Diamonds", "Six of Spades"}

// Loop through the 'cards' slice
for i, card := range cards {
	fmt.Println(i, card)
}
```

When you run this code, it will print the index and the card name for each element in the slice:

```Go
0 Ace of Spades
1 Five of Diamonds
2 Six of Spades
```
