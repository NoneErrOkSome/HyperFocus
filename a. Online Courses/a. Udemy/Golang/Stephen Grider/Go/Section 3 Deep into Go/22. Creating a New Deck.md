### `deck.go`

This file defines the `deck` type and any functions that operate on or create a deck.

Go

```Go
package main

import "fmt"

// Defines a new type 'deck' which is a slice of strings.
type deck []string

// Creates and returns a new deck of playing cards.
// This is not a receiver function because it doesn't need an existing deck to work.
func newDeck() deck {
	cards := deck{}

	cardSuits := []string{"Spades", "Diamonds", "Hearts", "Clubs"}
	cardValues := []string{"Ace", "Two", "Three", "Four"}

	for _, suit := range cardSuits {
		for _, value := range cardValues {
			cards = append(cards, value+" of "+suit)
		}
	}

	return cards
}

// A receiver function that prints the contents of a deck.
// Any variable of type 'deck' gets access to this method.
func (d deck) print() {
	for i, card := range d {
		fmt.Println(i, card)
	}
}
```

### `main.go`

This file contains the main entry point of the application. It uses the `deck` type and its functions.

Go

```Go
package main

// The main function where the program execution begins.
func main() {
	// Create a new deck by calling the newDeck() function.
	cards := newDeck()

	// Call the print() method on the 'cards' variable.
	cards.print()
}
```
