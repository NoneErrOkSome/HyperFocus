### Implementing the `deal` Function: Parameters and Multiple Return Values

We will now implement the `deal` function. This function introduces two important Go concepts: defining functions that accept parameters and functions that return multiple values.

#### 1. Defining the Function Signature

In `deck.go`, we start by defining the signature for our `deal` function. This signature outlines the parameters it accepts and the values it will return.

Go

```Go
// in deck.go
func deal(d deck, handSize int) (deck, deck) {
    // ...
}
```

Let's break down the new concepts here:

##### Function Parameters: `(d deck, handSize int)`

This is the first time we're creating a function that accepts arguments. In Go, you declare each parameter with its name followed by its type.

- `d deck`: The first parameter is named `d` and must be of type `deck`.
- `handSize int`: The second parameter is named `handSize` and must be of type `int`.

Because Go is statically-typed, you can _only_ call this function with arguments that match these types.

##### Multiple Return Values: `(deck, deck)`

A powerful feature of Go is the ability for a function to return multiple values. To do this, you wrap the return types in parentheses.

- `(deck, deck)`: This tells the Go compiler that the `deal` function will return **two** separate values, and both will be of type `deck`.

#### 2. Implementing the Function Body

The implementation uses the slice range syntax we discussed previously to split the deck into two pieces. The `return` keyword is followed by the two values, separated by a comma.

**The full implementation in `deck.go`**:

Go

```Go
func deal(d deck, handSize int) (deck, deck) {
	// Returns two new slices:
	// 1. From the start up to (but not including) handSize
	// 2. From handSize to the end
	return d[:handSize], d[handSize:]
}
```

#### 3. Calling the Function and Capturing Return Values

Now, let's use our new function in `main.go`. Since `deal` is in the same package (`main`), we can call it directly without any special import statement.

Because `deal` returns two values, we need to provide two variables to capture its output.

**`main.go` implementation**:

Go

```Go
func main() {
	cards := newDeck()

	// Call deal and capture both return values.
	// The first returned deck is assigned to 'hand'.
	// The second is assigned to 'remainingCards'.
	hand, remainingCards := deal(cards, 5)

	// We can call .print() on both because they are both of type 'deck'.
	hand.print()
	remainingCards.print()
}
```

When you run `go run main.go deck.go`, the output will show two separate lists of cards. You can confirm this because the indices printed by `print()` will start over from `0` for the second list, proving that `hand` and `remainingCards` are two distinct `deck` slices.
