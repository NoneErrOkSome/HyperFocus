### Dealing Cards: Understanding Slice Ranges in Go

The next feature for our project is the `deal` function. Its purpose is to take an existing deck of cards and split it into two smaller decks: a "hand" of a specified size, and the remaining cards. It's important to note that both the hand and the remainder will still be of type `deck`.

To implement this, we need to understand a core feature of Go: how to select a sub-section or "range" from a slice.

### Slice Fundamentals and Range Syntax

In Go, like in many other languages, slices are zero-indexed, meaning the first element is at index `0`. To select a portion of a slice, you use the `[start:end]` syntax.

**The Rules of Slice Ranges:**

1. The `start` index is **inclusive** (the element at this position is included in the result).
2. The `end` index is **exclusive** (the slice goes _up to_, but does not include, the element at this position).

Example:

Imagine a slice named fruits: ["apple", "banana", "grape", "orange"]

- `fruits[0:2]` would return a new slice containing `["apple", "banana"]`. It starts at index 0 and goes up to (but not including) index 2.

#### Shorthand Syntax

Go provides convenient shortcuts for slicing from the beginning or to the end of a slice:

- **`mySlice[:end]`**: If you omit the start index, Go assumes you want to start from the very beginning (index 0).
    
    - `fruits[:2]` is the same as `fruits[0:2]` and returns `["apple", "banana"]`.
- **`mySlice[start:]`**: If you omit the end index, Go assumes you want to go all the way to the very end of the slice.
    
    - `fruits[2:]` would return `["grape", "orange"]`.

### Implementing the `deal` Function

We can now use this slice syntax to easily implement our `deal` function. The function will accept a deck and an integer (`handSize`) and will return two separate decks.

This function is added to the `deck.go` file:

Go

```Go
// deal takes a deck and a handSize and returns two new decks.
func deal(d deck, handSize int) (deck, deck) {
    // Slices from the start up to (but not including) handSize
    hand := d[:handSize]

    // Slices from handSize to the very end of the deck
    remainingDeck := d[handSize:]

    return hand, remainingDeck
}
```

Or, more concisely:

Go

```Go
func deal(d deck, handSize int) (deck, deck) {
	return d[:handSize], d[handSize:]
}
```

Let's see how this works in `main.go`:

Go

```Go
func main() {
    cards := newDeck()
    
    // Deal a hand of 5 cards
    hand, remainingCards := deal(cards, 5)

    // 'hand' will contain the first 5 cards
    // 'remainingCards' will contain the rest of the deck
    hand.print()
    remainingCards.print()
}
```

Go's slice syntax provides a powerful and readable way to manage subsets of data, making functions like `deal` simple and elegant to write.
