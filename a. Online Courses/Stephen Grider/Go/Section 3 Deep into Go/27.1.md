### `deck.go`

This file contains the `deck` type definition and all its associated functions.


```Go
package main

import (
	"fmt"
	"strings"
)

// Defines a new type 'deck' which is a slice of strings.
type deck []string

// Creates and returns a new deck of playing cards.
func newDeck() deck {
	cards := deck{}

	cardSuits := []string{"Spades", "Diamonds", "Hearts", "Clubs"}
	cardValues := []string{"Ace", "Two", "Three", "Four"}

	for _, suit := range cardSuits {
		for _, value := range cardValues {
			cards = append(cards, value+" of "+suit)
		}
	}

	return cards
}

// A receiver function that prints the contents of a deck.
func (d deck) print() {
	for i, card := range d {
		fmt.Println(i, card)
	}
}

// A function that splits a deck into a hand and the remaining cards.
func deal(d deck, handSize int) (deck, deck) {
	return d[:handSize], d[handSize:]
}

// A receiver function that converts a deck into a single, comma-separated string.
func (d deck) toString() string {
	return strings.Join([]string(d), ",")
}
```

### `main.go`

This file contains the main entry point for the program, which creates a deck and tests the `toString` function.

Go

```Go
package main

import "fmt"

func main() {
	cards := newDeck()
	fmt.Println(cards.toString())
}
```
