## Creating Custom Types and Receiver Functions in Go

In Go, you can define custom types to better model the data in your application. This allows you to attach specific functions to these types, leading to more organized and maintainable code.

### 1. Introduction to Custom Types

Custom types in Go allow you to extend the functionality of existing types by creating new, descriptive names for them. This makes your code more readable and semantically meaningful.

#### Example: Defining a Custom Type

To create a custom type, use a **type declaration**. In our project, we'll define `deck` as a slice of strings (`[]string`) to represent a deck of cards.

```go
// Create a new type 'deck'
// which is a slice of strings
type deck []string
```

### 2. Creating and Using Custom Types

Once you have defined your custom type, you can use it just like any other type in Go.

#### Example: Using the `deck` Type

You can replace instances where you would typically use `[]string` with your new `deck` type.

```go
cards := newDeck() // Using our custom 'deck' type
```

### 3. Compiling Multi-File Projects

When your project spans multiple files (e.g., `main.go` and `deck.go`), ensure all files are compiled together using:

```bash
go run main.go deck.go
```

### 4. Adding Functionality with Receiver Functions

Receiver functions allow you to associate methods specifically with your custom types, akin to methods on classes in object-oriented languages.

#### Syntax & Structure of Receiver Functions

The syntax for defining a receiver function involves placing the receiver before the function name:

```go
func (d deck) print() {
    for i, card := range d {
        fmt.Println(i, card)
    }
}
```

- **Receiver `(d deck)`**: Connects this function to instances of `deck`. The receiver variable (`d`) acts like `this` or `self`.
- **Function Name `print()`**: Defines what action is performed on the `deck`.

#### Example: Calling Receiver Functions

You can invoke receiver functions using dot notation from other parts of your program:

```go
package main

func main() {
    cards := newDeck()
    cards.print()
}
```

### 5. Complete Example in Context

Here's how the complete implementation might look across two files in your project:

#### File: `deck.go`

```go
package main

import "fmt"

type deck []string

func newDeck() deck {
    return deck{
        "Ace of Spades", "Two of Spades", "Three of Spades",
        "Ace of Diamonds", "Two of Diamonds", "Three of Diamonds",
    }
}

func (d deck) print() {
    for i, card := range d {
        fmt.Println(i, card)
    }
}
```

#### File: `main.go`

```go
package main

func main() {
    cards := newDeck()
    cards.print()
}
```

By organizing code into custom types and associated receiver functions, you enhance both readability and functionality. To run this setup:

```bash

```

This command compiles both source files together, enabling seamless interaction between different parts of your project through well-defined interfaces.
