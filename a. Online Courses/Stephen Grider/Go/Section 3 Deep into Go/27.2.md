#### `newDeck()`

```Go
func newDeck() deck {
	cards := deck{}

	cardSuits := []string{"Spades", "Diamonds", "Hearts", "Clubs"}
	cardValues := []string{"Ace", "Two", "Three", "Four"}

	for _, suit := range cardSuits {
		for _, value := range cardValues {
			cards = append(cards, value+" of "+suit)
		}
	}

	return cards
}
```

- **What it does:** Creates and returns a new, ordered deck of playing cards.
- **How it works:** It initializes an empty `deck` slice. It then iterates through two other slices, `cardSuits` and `cardValues`, using nested `for` loops. In each iteration, it combines a suit and a value to create a card string (e.g., "Ace of Spades") and appends it to the `deck`. Finally, it returns the completed deck.

```Go
func (d deck) print() {
	for i, card := range d {
		fmt.Println(i, card)
	}
}
```

- **What it does:** This is a receiver function that iterates through a deck of cards and prints each card to the console, along with its index number.
- **How it works:** As a receiver on the `deck` type, it can be called on any variable of type `deck`. It uses a `for...range` loop to get the index (`i`) and value (`card`) of each element in the `d` slice and prints them using `fmt.Println()`.

#### `deal(d deck, handSize int)`

Go

```Go
func deal(d deck, handSize int) (deck, deck) {
	return d[:handSize], d[handSize:]
}
```

- **What it does:** Takes a deck and a hand size as arguments and splits the deck into two new decks: a "hand" and the "remaining cards."
- **How it works:** It uses Go's slice syntax. `d[:handSize]` creates a new slice containing the elements from the beginning up to the `handSize`. `d[handSize:]` creates another new slice with the elements from `handSize` to the end. It then returns these two new `deck` slices.

#### `(d deck) shuffle()`

Go

```Go
func (d deck) shuffle() {
	source := rand.NewSource(time.Now().UnixNano())
	r := rand.New(source)

	for i := range d {
		newPosition := r.Intn(len(d) - 1)

		d[i], d[newPosition] = d[newPosition], d[i]
	}
}
```

- **What it does:** This receiver function randomly shuffles the order of cards in a deck.
- **How it works:** It generates a new random number source using the current time (`time.Now().UnixNano()`) to ensure the shuffle is different each time the program runs. It then loops through the deck. For each index `i`, it generates a random new position `newPosition` within the bounds of the deck. Finally, it swaps the cards at index `i` and `newPosition`.
