### Saving Data: Interacting with the Hard Drive in Go

Our next goal is to implement the `saveToFile` and `newDeckFromFile` functions for our `cards` project. This involves a common programming task: writing data to and reading data from the computer's hard drive.

Whenever a Go program needs to interact with the underlying operating system or hardware, we turn to Go's powerful **standard library** of packages.

#### 1. Finding the Right Tool: The `io/ioutil` Package

To find the right tool for file I/O (Input/Output), we can browse the standard library documentation at **golang.org/pkg**. For simple file operations, a very useful package is `io/ioutil`.

Within the `ioutil` package, there is a function perfectly suited for our needs:

- **`WriteFile`**: This function writes data to a named file, creating the file if it doesn't already exist.

#### 2. Understanding `ioutil.WriteFile`

The function signature for `WriteFile` tells us exactly what it needs:

`func WriteFile(filename string, data []byte, perm os.FileMode) error`

Let's break down its parameters:

1. **`filename string`**: The name of the file you want to save (e.g., `"my_deck.txt"`).
2. **`data []byte`**: The actual content you want to write into the file. The type `[]byte` is a **byte slice**.
3. **`perm os.FileMode`**: The permissions to set on the file (e.g., `0666`). This determines who can read, write, or execute the file.

The most important and new concept here is the `data []byte` parameter. To use this function, we must provide our data as a byte slice.

---

### 3. What is a Byte Slice (`[]byte`)?

A byte slice can seem confusing at first, but here is a simple way to think about it:

**A byte slice is the computer's representation of a string.**

- A **`string`** is a sequence of characters that is human-readable (e.g., "Hi there!").
- A **`[]byte`** (byte slice) is a slice of numbers, where each number represents a character according to a standard like ASCII.

For example, the string "Hi there!" can be represented as the following byte slice:

[72 105 32 116 104 101 114 101 33]

Each number corresponds to a character:

- `72` = 'H'
- `105` = 'i'
- `32` = ' ' (space)
- ...and so on.

While we as developers almost always work with the `string` type for readability, many functions in Go's standard library (especially those dealing with files, networking, etc.) work with the raw `[]byte` representation.
