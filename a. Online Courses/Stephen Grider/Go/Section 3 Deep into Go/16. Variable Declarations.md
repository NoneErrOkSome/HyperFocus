### Go Fundamentals: Variables and Types

This guide explores the basics of creating and using variables in Go. We will cover how Go's type system works and the different ways you can declare variables.

#### The Goal: Create and Print a Variable

Our initial task is simple: create a variable to hold the name of a playing card and then print it to the console.

The code to accomplish this, as seen in `cards/main.go`, looks like this:

Go

```Go
package main

import "fmt"

func main() {
	var card string = "Ace of Spades"
	fmt.Println(card)
}
```

When you write code that uses a function from another package (like `Println` from `fmt`), a good Go-aware editor like VS Code will often add the required `import "fmt"` statement for you automatically.

### Static vs. Dynamic Typing: A Core Go Concept

To understand variable declaration in Go, it's crucial to know that Go is a **statically-typed language**. This is a key difference from dynamically-typed languages like Python, Ruby, or JavaScript.

- **Statically-Typed (Go, C++, Java)**: You, the developer, must specify the type of data a variable will hold (e.g., string, number, boolean). The Go compiler enforces this rule, meaning you cannot assign a different type of data to that variable later. This catches potential bugs before the program even runs.
    
- **Dynamically-Typed (Python, JavaScript)**: The language interpreter figures out the variable's type at runtime. You can assign a number to a variable and then reassign a string to that same variable without an error.
    

For example, the following is valid in JavaScript but would cause a compiler error in Go:

JavaScript

```Go

// This is okay in a dynamically-typed language
var myValue = 123;       // myValue is a number
myValue = "some text";   // Now myValue is a string
```

In Go, once we declare `var card string`, the `card` variable can _only_ ever hold a string value.

#### Basic Data Types in Go

Go comes with several fundamental data types. The most common ones you'll start with are:

- **`string`**: A sequence of characters, like `"Hello, world!"`.
- **`int`**: Whole numbers (integers), like `-10`, `0`, or `9000`.
- **`float64`**: Numbers with a decimal point, like `3.14` or `99.99`.
- **`bool`**: A boolean value, which can only be `true` or `false`.

### Declaring Variables in Go

Go provides two primary ways to declare and initialize variables.

#### 1. The Long Form: `var name type`

The most explicit way to declare a variable is using the `var` keyword, followed by the variable name and its type.

Go

```Go
var card string = "Ace of Spades"
```

Let's break this down:

- `var`: A keyword that tells Go you are about to declare a new variable.
- `card`: The name you are giving to this new variable.
- `string`: The type declaration. This tells the compiler that the `card` variable will only ever hold values of type `string`.
- `= "Ace of Spades"`: The assignment. The string value `"Ace of Spades"` is assigned to the `card` variable.

#### 2. The Short Form: `:=` and Type Inference

The more common and idiomatic way to declare and initialize a variable in Go is with the `:=` operator.

Go

```Go

card := "Ace of Spades"
```

This single line is **100% equivalent** to `var card string = "Ace of Spades"`.

The `:=` syntax tells the Go compiler to perform **type inference**. The compiler looks at the value on the right side of the `:=` (in this case, a string) and automatically infers that the `card` variable should be of type `string`.

### The Rules of Assignment: `:=` vs. `=`

This is a very common point of confusion for new Go developers. The rule is simple:

- Use `:=` **only** when declaring a **new** variable for the first time.
- Use `=` when reassigning a value to an **existing** variable.

**Example:**

Go

```Go

// Initialize a NEW variable 'card'
card := "Ace of Spades"

// REASSIGN an existing variable 'card'
card = "Five of Diamonds" // No colon needed

// This would cause an error, because 'card' already exists:
// card := "King of Hearts"  // ERROR: no new variables on left side of :=
```
