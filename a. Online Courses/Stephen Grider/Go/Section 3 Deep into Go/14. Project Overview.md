### Project Overview: Building a Deck of Cards Package in Go

This project is your first practical application in Go, designed to teach you fundamental concepts by creating a package that simulates a deck of playing cards. You will build a collection of functions to create, shuffle, deal, and save a deck to your computer.

### Core Concept: The `deck` Type

Before we can work with a deck of cards, we need to decide how to represent it in our code. A deck is a collection of cards, and each card can be represented as a simple string, like "Ace of Spades".

In Go, we can create a new custom type called **`deck`** that is a "slice of strings". A slice is a Go data structure that manages a list of elements of the same type.

This is defined in `deck.go` with a **type declaration**:

Go

```
// Create a new type of 'deck'
// which is a slice of strings
type deck []string
```

By creating a `deck` type, we can now add specific functions that only work with decks of cards. These are called **receiver functions**.

### Project Functionality

The project will be built around a few key functions that provide the core features for managing a deck of cards.

#### 1. Creating a New Deck: `newDeck()`

The first step is to generate a standard deck of cards. The `newDeck()` function is responsible for creating and returning a complete, ordered deck.

- **Purpose**: To create a list of 52 playing cards (or a smaller deck for testing, as seen in the course example).
- **How it Works**: The function will create two slices of strings: one for the suits (`"Spades"`, `"Hearts"`, etc.) and one for the values (`"Ace"`, `"Two"`, etc.). It then uses nested `for` loops to iterate over both slices, combining each suit with each value to create a card string (e.g., `"Ace" + " of " + "Spades"`). Each new card is appended to the `deck` slice.

**From `deck.go`**:

Go

```
func newDeck() deck {
	cards := deck{}

	cardSuits := []string{"Spades", "Diamonds", "Hearts", "Clubs"}
	cardValues := []string{"Ace", "Two", "Three", "Four"}

	for _, suit := range cardSuits {
		for _, value := range cardValues {
			cards = append(cards, value+" of "+suit)
		}
	}

	return cards
}
```

#### 2. Dealing Cards: `deal()`

The `deal` function simulates dealing a hand of cards from the deck.

- **Purpose**: To split a single deck into two: one representing the "hand" of cards dealt, and the other representing the remaining cards in the deck.
- **How it Works**: This function takes the deck and a `handSize` (an integer) as arguments. It uses Go's slice syntax to split the underlying list of cards. For example, `d[:handSize]` creates a new slice from the beginning of `d` up to the `handSize` index.

**From `deck.go`**:

Go

```
func deal(d deck, handSize int) (deck, deck) {
	return d[:handSize], d[handSize:]
}
```

#### 3. Shuffling the Deck: `shuffle()`

To make our card simulation realistic, we need to be able to shuffle the deck randomly.

- **Purpose**: To reorder the cards in a deck in a random sequence.
- **How it Works**: The `shuffle` function is a receiver function that modifies the deck it's called on. It iterates through each card's index (`i`) and, for each one, generates a random number (`newPosition`) between 0 and the last index of the deck. It then swaps the card at `i` with the card at `newPosition`. To ensure the shuffle is different every time the program runs, it uses the current time to create a unique "seed" for the random number generator.

**From `deck.go`**:

Go

```
func (d deck) shuffle() {
	source := rand.NewSource(time.Now().UnixNano())
	r := rand.New(source)

	for i := range d {
		newPosition := r.Intn(len(d) - 1)

		d[i], d[newPosition] = d[newPosition], d[i]
	}
}
```

#### 4. Saving and Loading the Deck 💾

Finally, you'll add the ability to save your deck to a file and load it back into the program later.

- **`saveToFile(filename string)`**: This function first converts the `deck` (a slice of strings) into a single string, with each card separated by a comma. It then writes this single string as raw data (a byte slice) to a file on your hard drive.
- **`newDeckFromFile(filename string)`**: This function does the reverse. It reads a file from the hard drive, which returns a slice of bytes. If there's an error (e.g., the file doesn't exist), it will print the error and exit the program. Otherwise, it converts the byte slice into a string and then splits that string by the commas to recreate the `deck` slice.
