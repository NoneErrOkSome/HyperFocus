### Setting Up a New Go Project: The "Cards" Example

Every Go application begins with a well-organized project directory and a primary file that serves as its entry point. This guide walks you through the initial setup for a new executable program, using the "cards" project as a practical example.

#### Step 1: Create a Project Directory

First, it is standard practice to create a dedicated folder for each new project. This keeps all your source code and related files neatly organized in one place.

For this project, you would create a new folder named `cards`. This folder will contain all the files related to your deck of cards application.

#### Step 2: Create the `main.go` File

Inside your project directory (`cards`), the next step is to create the primary source file. By convention, for an executable program, this file is named `main.go`. This file acts as the main entry point for your application.

#### Step 3: Write the Boilerplate Code

Every executable Go program starts with the same basic "boilerplate" code to define its package and its starting function. This is clearly demonstrated in the `main.go` file for the cards project.

##### `package main`

The very first line of your `main.go` file must be the package declaration.

Go

```
package main
```

- **Purpose**: This line declares that the file belongs to the `main` package.
- **Significance**: As we've discussed, declaring a package as `main` is special. It tells the Go compiler that the purpose of this package is to be compiled into a standalone **executable file**—a program that you can run directly from your terminal.

##### `func main()`

After the package declaration, you must define the `main` function.

Go

```
func main() {
	// Program execution starts here
}
```

- **Purpose**: This defines the function named `main`, which is the entry point of your program.
- **The Rule**: Whenever a package is named `main`, Go requires it to have a `main()` function. When you run your compiled program, the code inside this function is the very first thing to be executed.

Once you have this basic structure in place, as seen in `cards/main.go`, your project is set up and ready for you to start adding the specific logic for your application, such as creating and managing a deck of cards.
