In Go, a **package** is a fundamental concept for organizing code. Think of it as a project or a container for a collection of related source code files. For any application you build, all its `.go` files will typically belong to a single package. A crucial rule is that every `.go` file must declare its package on the very first line. For instance, if you have three files that are part of the same project, they must all begin with the same declaration, like `package main`.

---

## Executable vs. Reusable Packages

Go has two distinct types of packages, and the name you give the package determines its type.

### Executable Packages 🏃‍♂️

An **executable package** is one that can be compiled into a runnable program file. When you want to create an application that performs a specific task, you create an executable package.

To make a package executable, you must name it **`main`**.

Go

```Go
package main
```

When the Go compiler sees `package main`, it knows your intention is to produce a standalone executable file (e.g., `main` on Linux/macOS or `main.exe` on Windows).

Furthermore, every executable package **must** have a function called `main()`. This function serves as the starting point for your program.

**Example:**

Go

```Go
// main.go
package main

import "fmt"

// The program starts execution here
func main() {
    fmt.Println("Hello, world!")
}
```

Running the command `go build main.go` will compile this code and produce a runnable file named `main`.

### Reusable Packages 📚

A **reusable package**, often called a library or dependency, contains code that is intended to be used by other packages. It is not meant to be run on its own. These packages are perfect for storing helper functions or shared logic that you might want to use across multiple projects.

You create a reusable package by giving it **any name other than `main`**.

For example, if you named your package `calculator`, it would be a reusable package.

**Example:**

Go

```Go
// calculator/math.go
package calculator

// Add returns the sum of two integers.
func Add(a int, b int) int {
    return a + b
}
```

If you were to run `go build` on this file, it would not produce an executable. Instead, another program could import this `calculator` package to use its `Add` function.

### Summary

|   |   |   |
|---|---|---|
|**Feature**|**Executable Package**|**Reusable Package**|
|**Package Name**|Must be `main`|Any name other than `main` (e.g., `utils`, `api`)|
|**Purpose**|To be compiled into a runnable program.|To be used as a library or dependency in other projects.|
|**`main` Function**|Required (`func main()`). It's the program's entry point.|Not required.|
|**Output of `go build`**|A single executable file.|No executable file is produced.|
