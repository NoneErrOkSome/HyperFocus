The `import` statement in Go is used to give your current package access to code from another package. By default, a package you create is isolated and cannot use functionality defined elsewhere. The `import` keyword creates a link, allowing you to use functions, types, and variables from other packages.

---

### Understanding `import "fmt"`

The line `import "fmt"` specifically grants your package access to the **`fmt`** package.

- **What is `fmt`?** It's a standard library package included with Go by default. The name is a shorthand for "format."
- **What does it do?** Its main purpose is to handle formatted input and output, such as printing text to the terminal. The `Println` function we use in a "Hello, world!" program comes from this package.

When you import `"fmt"`, you can then call functions from that package by prefixing them with the package name, like **`fmt.Println()`**.

**Example:**

Go

```go
package main

import "fmt" // Gives us access to the "fmt" package

func main() {
    // We can now use Println, a function defined in "fmt"
    name := "World"
    fmt.Println("Hello,", name) 
}
```

---

### Standard vs. Third-Party Packages 🌐

You aren't limited to using only the packages that come with Go. The `import` statement works for two main types of packages:

1. **Standard Library Packages**: These are built-in packages like `fmt`, `math` (for mathematical functions), or `net/http` (for building web servers). They provide a robust foundation for common programming tasks.
2. **Third-Party Packages**: These are reusable packages created and shared by other developers. You can import them to add specialized functionality to your project, like a new database driver or a specific API client, without having to write the code from scratch.

Think of it as building a project: the standard library gives you the basic tools (hammer, nails), while third-party packages are like pre-built components (windows, doors) that you can easily add.

### The Importance of Documentation 📖

A key skill in learning Go is learning how to use its standard library effectively. The official Go documentation is the best resource for this.

You can explore all standard library packages at **[golang.org/pkg](https://golang.org/pkg/)**.

This website provides detailed information on what each package does and a complete list of all the functions it contains. For example, visiting the `fmt` package page will show you all the different ways you can format and print strings, numbers, and other data structures. As a developer, you will frequently consult these official docs to understand how to best leverage Go's built-in features.
